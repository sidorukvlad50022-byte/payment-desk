Опублікувати зміни

Зміни буде збережено в GitHub. Після завершення публікації їх побачать усі відвідувачі.

sidorukvlad50022-byte / payment-desk main

Токен використовується тільки для цього сеансу й не записується у файли або сховище браузера.

Як отримати токен?
  1. Відкрийте створення токена GitHub ↗
  2. У Repository access виберіть Only select repositories → payment-desk.
  3. У Repository permissions надайте Contents → Read and write.
  4. Згенеруйте токен і вставте його в поле вище.
